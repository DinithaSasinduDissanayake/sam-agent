What we need:
- All brands of frozen meatballs sold in Sri Lanka (Kresta, Golden, Primo, Keells, Cargills, etc.)
- Prices at major retailers (Keells, Cargills, Laugfs, Arpico, online delivery)
- Package weight and price per 100g (for comparison)
- Nutritional info if available (protein, fat, calories per serving)
- Where each brand is manufactured / imported from

How to work:
1. Start with web searches to find available products.
2. Follow the leads — if one search mentions a brand, search specifically for that brand's price.
3. If you hit a dead end on one product, move to the next.

Rules:
- Every price or fact must be traceable to a source. Say "[Source: URL]" next to each data point.
- If you cannot find specific info (price, nutrition), say "not found" — never invent numbers.
- Write a clear summary table at the end.
- Total length: be thorough but concise.

